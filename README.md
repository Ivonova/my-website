# Iulia Ivanova — Portfolio

This is a static HTML/CSS/JavaScript portfolio website.

## Files
- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and scroll animations

## Open locally
Double-click `index.html` to open it in a browser.

## Publish on GitHub Pages
Create a repository, upload the three files to the root, then enable GitHub Pages in:
Settings → Pages → Deploy from branch → main → / (root)
